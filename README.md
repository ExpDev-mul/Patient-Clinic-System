# 🏥 Patient-Clinic System

A full-stack web application designed for streamlined **patient-clinic communication**, featuring secure authentication, appointment management, and messaging.

## 🔧 Features

- 🔐 JWT-based authentication for secure login
- 🍪 Cookie-caching for persistent sessions
- 🗓️ Appointment scheduling and management
- 💬 Robust messaging system for patient-clinic communication
- 🌐 Fully functional web interface

## 🛠️ Requirements

- Node.js and npm (for the backend)
- Frontend: HTML, CSS, JavaScript
- Backend: Express.js, JWT, MongoDB (or preferred DB)

Install dependencies:
```bash
npm install
```

## 🧑‍💻 Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/ExpDev-mul/Patient-Clinic-System.git
   cd Patient-Clinic-System
   ```

2. Install frontend and backend dependencies:
   ```bash
   cd frontend && npm install
   cd ../backend && npm install
   ```

3. Start both the frontend and backend servers:
   ```bash
   npm run dev
   ```

4. Open the application in your browser.

## 📌 Notes

This web app provides secure messaging and appointment features, with a focus on efficient and reliable communication between patients and clinics. Ideal for use in telemedicine, healthcare apps, and patient management systems.
